# Idle Slot Machine Game

This project is a web-based idle game that combines the addictive mechanics of a slot machine with the long-term progression of an idle game. Players start with a single, classic slot machine and must master it to unlock and upgrade a series of increasingly advanced machines, building a casino empire.

## Project Plan

The core concept is to create a compelling gameplay loop where players are always working towards the next meaningful upgrade or unlock. The game will feature an "Aesthetic Evolution," starting with a "Vintage Vegas Noir" theme and transitioning to a "Cyber-Neon High-Stakes" theme as the player progresses. The user experience will be enhanced by a "Dopamine Symphony" of satisfying sound effects and visual "juice" to make every win feel rewarding.

## Installation Guide

This is a static web application built with HTML, CSS, and vanilla JavaScript. No complex installation is required.

1.  **Clone or download the repository.**
2.  **Navigate to the project directory.**
3.  **Open the `index.html` file in your favorite web browser.**

That's it! The game will run directly in your browser.
